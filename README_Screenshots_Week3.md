# Week 3 – Screenshots README

## Purpose

This folder contains the screenshots for the Week 3 PHP practical work.

The screenshots provide visual evidence of the PHP program and its output while practicing multidimensional arrays and PHP array functions.

## Week 3 Practical File

The main PHP file used for this work is:

`practice.php`

The program demonstrates:

- Multidimensional arrays
- Accessing array elements with indexes
- Displaying values with `echo`
- Using `foreach`
- Checking arrays with `is_array()`
- Searching with `in_array()`
- Counting elements with `count()`
- Sorting with `sort()`
- Reverse sorting with `rsort()`
- Combining arrays with `array_merge()`
