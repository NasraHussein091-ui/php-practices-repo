# Week 4 - Textbox and Form

## File
- `textbox.php`

## About
This PHP exercise creates a simple HTML form with a username field, password field, textarea, gender radio buttons, and Reset and Register buttons. It then displays the submitted form values.

## How to run
1. Put the project folder inside your local PHP server directory, such as `htdocs` in XAMPP.
2. Start Apache in XAMPP.
3. Open `textbox.php` through your local server in a browser.
4. Fill in the form and click **Register** to submit it.
