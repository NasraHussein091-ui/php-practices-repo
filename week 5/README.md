# Week 5 Form

This folder contains the PHP form exercise for Week 5.

## File
- `form.php` — the PHP file for the form exercise.

## How to Run
1. Open the project folder in your code editor.
2. Run the PHP project using a local PHP server, such as XAMPP.
3. Open the local address for `form.php` in your browser.
4. Enter the requested information in the form and test it.

The `screenshorts week5` folder contains screenshots related to this week's work.
